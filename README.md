## 🚀 Öne Çıkan Özellikler
* **🍱 Modern Bento-Grid Mimarisi:** Yetenekler, projeler ve tecrübelerin kartlar halinde şık, okunabilir ve dengeli sunumu.
* **🌑 Koyu Minimalist & Glassmorphism Tema:** Obsidian siyahı arka plan, yarı saydam kartlar, modern blur efektleri ve altın sarısı aksan renkler.
* **⚡ Sıfır Bağımlılık (Zero Build Time):** Herhangi bir `npm install` veya karmaşık derleme işlemine gerek duymaksızın saf tarayıcı motorunda milisaniyeler içinde açılır.
* **🔥 Gerçek Zamanlı Firebase Firestore Entegrasyonu:**
  * İçerik, proje ve yeteneklerin anlık senkronizasyonu.
  * Ziyaretçiler için güvenli, şema doğrulamalı iletişim formu.
* **🛡️ Kurşungeçirmez Güvenlik Kuralları:** Admin UID doğrulamalı Firestore Security Rules v2 ile tam yetki koruması.
* **📄 Entegre CV / Özgeçmiş Sayfası (`cv.html`):** Tek tıkla A4 formatında PDF olarak kaydedilebilen kurumsal özgeçmiş görünümü.
* **📱 %100 Mobil Uyumlu (Responsive):** Telefon, tablet ve geniş ekran monitörlerde kusursuz deneyim.
