# Salahattin Açıkgöz - Koyu Minimalist Portföy Web Sitesi

Bu proje, **Salahattin Açıkgöz** için hazırlanan, modern bento-grid yapısında, koyu minimalist temaya sahip yüksek performanslı yazılımcı portföy web sitesidir.

## 🚀 Öne Çıkan Özellikler

- **Modern Bento-Grid Düzeni:** Bilgileri kartlar halinde şık ve anlaşılır sunum.
- **Koyu Minimalist Tema:** Obsidian koyu arka plan, glassmorphism kart efektleri ve neon renk aksanları.
- **Dinamik Bölümler:**
  - **Hero:** Unvanlar (*Yazılım Geliştirici, API, Veritabanı, RPA*), canlı çalışma durumu ve tek tıkla e-posta kopyalama.
  - **Hakkımda:** Uzmanlık alanları ve çalışma prensipleri.
  - **Yetenekler (Tech Stack):** Yetenek rozetleri.
  - **Deneyimler:** Zaman çizelgesi (Timeline).
  - **Projeler:** Filtrelenebilir bento kartlar ve detay modalleri.
  - **İletişim:** İletişim formu ve sosyal bağlantılar.
- **Çalıştırma Bağımsızlığı:** Herhangi bir derleme (build) veya `npm install` gerektirmeksizin doğrudan web tarayıcısında açılır.

## 💻 Nasıl Çalıştırılır?

1. `C:\Users\salahattin.acikgoz\.gemini\antigravity\scratch\salahattin-portfolio\` klasörüne gidin.
2. `index.html` dosyasına çift tıklayarak istediğiniz web tarayıcısında (Chrome, Edge, Firefox, Safari) doğrudan açabilirsiniz.

## 🌐 İnternette Nasıl Yayınlanır? (Vercel / Netlify / GitHub Pages)

- **Vercel:** Vercel hesabınızda "New Project" seçip bu proje klasörünü sürükleyip bırakarak saniyeler içinde canlıya alabilirsiniz.
- **GitHub Pages:** Bir GitHub reposu oluşturup dosyaları yükledikten sonra *Settings > Pages* bölümünden yayına alabilirsiniz.
